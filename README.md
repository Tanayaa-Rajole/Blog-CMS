# Lightweight Blog CMS

A minimal, file-based Content Management System (CMS) built with Node.js, Express, and EJS. Designed for fast deployments without requiring a database engine.

## Features

- **Full CRUD Support**: Create, read, update, and delete blog posts seamlessly.
- **Zero-DB Setup**: Persists content using local structured JSON data.
- **Clean UI**: Responsive CSS design with styled public feed and admin controls.
- **EJS Templating**: Modular view templates for easy layout modification.
